# Tinta Negra Tattoo

Landing page de un estudio de tatuajes con estética brutalista/underground.

## Stack

- React 19 + Vite + TypeScript
- Tailwind CSS v4
- Lucide React

## Desarrollo

```
npm install
npm run dev
```

## Build de producción

```
npm run build
```

El resultado se genera en la carpeta `dist/`.
